# 🎓 Rithika's Portfolio Website

A responsive, interactive personal portfolio website showcasing projects, skills, and contact information. Built with HTML5, CSS3, JavaScript, PHP, and MySQL as part of the **ApexPlanet 60-Day Full Stack Development Internship**.

---

## 🌐 Live Portfolio

**View the live portfolio:** https://rithikanagineni.github.io/portfolio-website/

---

## ✨ Features

### **Frontend Features**
- ✅ **Responsive Design** - Works perfectly on desktop, tablet, and mobile
- ✅ **Typing Animation** - Animated header text on homepage
- ✅ **Smooth Scrolling** - Navigate smoothly between sections
- ✅ **Dark Mode Toggle** - Switch between light and dark themes
- ✅ **Skill Progress Bars** - Visual representation of skill levels
- ✅ **Project Filtering** - Filter projects by category (Full Stack, Frontend, Backend, AI/ML)
- ✅ **Interactive Buttons** - Hover effects and animations
- ✅ **Resume Download** - Download resume directly from portfolio

### **Backend Features**
- ✅ **Contact Form** - Submit messages directly from portfolio
- ✅ **Database Integration** - Store messages in MySQL database
- ✅ **Admin Dashboard** - View, edit, search, and delete messages
- ✅ **CRUD Operations** - Complete Create, Read, Update, Delete functionality
- ✅ **Form Validation** - Client-side and server-side validation
- ✅ **Security** - SQL injection prevention with prepared statements
- ✅ **Search Functionality** - Search messages by name

### **Project Management**
- 📊 **18 Total Projects** - Showcase of diverse projects
- 🔴 **8 Real-Time Projects** - Mark real-world implementations
- 🏷️ **Project Categories** - Organized by technology stack
- 📱 **All Projects Page** - Dedicated page with filtering
