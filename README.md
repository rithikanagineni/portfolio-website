# portfolio-website

## Description
This is a full-stack portfolio website developed using HTML, CSS, JavaScript, PHP, and MySQL.

## Features
- Responsive design
- Dark mode toggle
- Project filtering system
- Contact form with database integration
- Admin panel to view messages

## Technologies Used
- HTML
- CSS
- JavaScript
- PHP
- MySQL

## How to Run
1. Install XAMPP
2. Place project in htdocs folder
3. Start Apache and MySQL
4. Open http://localhost/portfolio
